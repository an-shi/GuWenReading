# AI 提示词与模型

最后更新：2026-11-17

## 1. 运行方式

古文阅读器不包含内置 AI 服务。所有 AI 请求由用户在“我的 → AI 模型”中配置的服务商发起：

- OpenAI 兼容接口（DeepSeek、通义千问、豆包、Kimi、智谱、硅基流动、腾讯混元、百度千帆、MiniMax、OpenRouter 等）
- OpenAI、Anthropic、Google Gemini
- Ollama（本地或局域网）

新增服务商时可选择常见供应商预设，自动填写接口地址。填写 API Key 后可调用服务商的模型列表接口，读取并选择要使用的模型；列表中的输入模态、上下文长度和输出上限会一并保存。多模态模型会标记“图片理解”能力。

接口密钥保存在系统安全存储中。应用不会把密钥写入日志、备份清单或界面明文。

章节翻译、知识抽取的调用链、缓存和费用优化建议见 [AI_PIPELINE_COSTS.md](AI_PIPELINE_COSTS.md)。

## 2. 模型角色

- **默认翻译模型**：逐句翻译、单句重译。
- **默认问答模型**：AI 解释、阅读助手。
- **默认知识抽取模型**：联合抽取实体、关系和历史事件；未配置时回退到默认问答模型。

模型配置包含：

- 模型标识（API 使用的 `model` 字段）
- 显示名称
- 上下文长度
- 最大输出
- 超时
- 能力（翻译/问答与抽取/图片理解）
- 是否支持结构化 JSON 输出
- 默认翻译/默认问答/默认知识抽取标记
- 输入、输出、缓存读取、缓存写入单价（每百万 Token，币种由用户自行统一）

## 3. 提示词目录

提示词保存在 SQLite 的 `prompt_templates` 表，支持版本、编辑与启用/回滚。

| key | 名称 | 用途 |
| --- | --- | --- |
| `translation` | 文言文翻译（均衡） | 章节分批翻译，返回 JSON 译文；请求内使用短整数索引 |
| `knowledge_extract` | 联合知识抽取 | 一次返回实体、关系和历史事件，按块处理，证据使用句子短索引 |
| `sentence_explain` | 句子释义 | 难词、句式、典故与含义 |
| `entity_extract` | 历史人物与实体抽取 | 旧版独立实体提示词，保留用于兼容/自定义 |
| `relation_extract` | 人物关系抽取 | 旧版独立关系提示词，保留用于兼容/自定义 |
| `event_extract` | 历史事件抽取 | 旧版独立事件提示词，保留用于兼容/自定义 |
| `assistant` | 古籍阅读助手 | 检索增强问答、引用与 claims |
| `review` | 翻译质量检查 | 漏译、误译、增译、语气 |
| `word_glossary` | 词语释义 | 语境义与用法 |
| `historical_background` | 历史背景解释 | 制度、职官、地理、年代 |
| `conflict_analysis` | 史料冲突分析 | 多史料一致与冲突 |

## 4. 输出约束

结构化提示词要求模型只返回 JSON。应用会：

1. 去除 Markdown 围栏。
2. 截取第一个 `{` 到最后一个 `}`。
3. 解析失败时明确报错，不伪造结果。
4. 译文按 `sentence_id` 关联原文；缺失译文的句子标记失败。
5. 联合知识抽取的 `evidence` 是块内句子短索引，应用根据索引读取真实原文；没有有效证据的关系/事件不写入。
6. 向量/字段不要求模型返回 UUID、完整原文或冗长人物介绍。

## 5. 审核与保护

- AI 翻译不会覆盖人工译文。
- 重新翻译已有 AI 译文时，旧译文保留，新译文进入 `translation_reviews`。
- 采用候选后写入新版本，并保留历史版本。
- 知识抽取的实体、关系、事件默认待审核；用户可在人物资料、图谱、时间线中确认或驳回。

## 6. 本地缓存与计量

- `translation_sentence_cache`：逐句翻译缓存，Key 包含原文 Hash、上下文 Hash、模型、Prompt 版本和策略版本。批次边界变化不会使所有译文失效。
- `translation_cache`：批次级完整提示词缓存。
- `knowledge_chunk_cache`：知识抽取块级缓存，Key 包含章节、块索引、内容 Hash、模型、Prompt 版本和 Schema 版本。
- `knowledge_extraction_state`：章节级抽取状态，用于跳过未变化章节。
- `ai_usage`：每次 AI 请求的 Token、缓存 Token、费用、耗时、状态和估算标记。
- `tasks`：聚合本任务的 Token、费用、请求次数。

费用按模型配置的每百万 Token 单价计算；没有真实 usage 时使用保守估算并标记为估算。详见 [AI_PIPELINE_COSTS.md](AI_PIPELINE_COSTS.md)。

## 7. 隐私

- 原文与知识库数据默认不离开设备。
- 只有使用 AI 功能时，相关章节上下文才会发送到用户配置的服务商。
- 没有隐藏遥测或内置 API Key。
