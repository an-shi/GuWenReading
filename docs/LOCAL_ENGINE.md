# 本地文言文推测引擎

最后更新：2026-11-19

## 1. 定位

本地规则引擎，完全离线，不调用任何 Provider、不需要 API Key、不产生 Token 费用。结果标记为 `local_rule`，明确不是权威译文。

## 2. 模块

```text
app/lib/core/local/local_engine/lexicon.dart          词库、虚词、古今异义、固定句式
app/lib/core/local/local_engine/engine.dart           分词、句式、候选、置信度、理由
app/lib/core/local/local_engine/local_lexicon_service.dart  自定义词条、导入导出
```

## 3. 翻译模式

设置页“翻译引擎模式”：

- `ai`：原 AI 翻译。
- `local`：完全本地推测，零 API。
- `local_first`：高/中置信度本地保存，低置信度交给 AI。
- `ai_reference`：先生成本地参考，再附加到 AI Prompt 中校正（消耗 API）。

## 4. 词库

内置词库首次启动时幂等写入 SQLite 的 `local_lexicon_entries`（`is_custom = 0`），内置数据仅作为一次性种子；本地翻译引擎运行时只读取数据库，不再直接使用代码中的内存词表。

用户自定义词条（`is_custom = 1`）保存在同一张表，优先级高于内置词条，不覆盖内置原始记录。删除自定义覆盖后自动回退到内置数据库词条。

## 5. 缓存

`local_translation_cache` 的 Key 包含原文、前后句、词库版本和引擎版本。词库或规则版本变化后旧缓存不会命中。

## 6. 置信度

综合词库命中率、未知字数量、多义词数量、固定句式命中、省略补充等因素。输出 `high / medium / low` 和 0–1 分数。

## 7. 结果展示

- 阅读页显示“本地规则推测 · 非权威译文”。
- 句子菜单“查看推测依据”展示分词、释义、句式规则、不确定内容和候选译文。
- 用户手工修订本地译文时写入 `local_translation_revisions`，不自动修改公共词库。

## 8. 词库管理页面

设置页新增“词库”标签：

- 搜索词语或释义。
- 新增自定义词条：词语、词性、多个现代释义、来源。
- 编辑内置词条会创建个人覆盖，不修改内置原始记录。
- 编辑自定义词条，可修改词语/词性/释义/来源。
- 删除词条，删除后自动回退到内置数据库词条或原字。
- 所有词条真实存储在 `local_lexicon_entries`，引擎每次本地翻译从数据库加载。

## 9. 已知限制

- 词库规模有限，覆盖常见教学/史书高频词，不含完整古汉语词典。
- 语法分析为规则启发式，复杂长句、典故、专名和省略结构仍可能出错。
- 不是语言学意义上的完整 parser，不宣称达到人工翻译质量。
- 未内置第三方词典数据，避免版权问题；词条为项目自行整理。
